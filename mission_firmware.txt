## Requirements

1. **USB HID keyboard** (boot protocol compatible) toward the PC. No vendor USB interfaces. Must enumerate cleanly on Windows/Android hosts.
2. **BLE NUS peripheral** per PROTOCOL.md: name `VoiceKB`, NUS service 6E400001-..., RX write char 6E400002-..., TX notify 6E400003-..., DIS firmware rev `vk-1.0`.
3. **Typing engine**: RX bytes → HID key reports, US layout, shift handling for capitals/symbols, `\n`=Enter, `\t`=Tab, 0x08=Backspace, 0x00-escaped special keys (Esc, arrows, Del, Home, End, PgUp/PgDn, F1–F12) per PROTOCOL.md. Rate-limit ~15ms/keystroke. Robust to arbitrary BLE chunking (reassemble a byte stream; never split the 0x00 escape pair across processing).
4. **Security**: LE bonding required for RX writes (encrypted link). Pairing window: bondable 60s after single press of the dongle's onboard button; outside the window only bonded centrals connect. If the button proves unusable (UF2 bootloader conflict), fall back to always-bondable and note it in README. Bond keys persisted in flash (settings subsystem).
5. **TX status notifies**: 0x00 idle / 0x01 busy, best effort.
6. LED feedback if the dongle LED is free: slow blink = advertising/pairing window, solid = connected. (Nice-to-have, don't break the build over it.)
